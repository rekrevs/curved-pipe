# T-0014: Retain pilot lessons: fix probe sign-loss + rate overflow, add nonlinear Gauss-Seidel skill

**Status**: DONE | **Size**: M
**Phase**: -

## Context

ADSD's retain step, driven by the T-0012 pilot (docs/adsd/pilot.md). Arm B
exposed two probe defects and found a remedy the library lacked:

1. Sign loss: with only nonnegative magnitude observables (max|field|), an
   alternating mode lambda ~ -9.3 was reported as +2.1.
2. `empirical_rate` printed ~1e300 on traces that converge exactly.
3. Nonlinear Gauss-Seidel at the inner level (one SOR sweep per field per
   outer iteration) made every case contract with no averaging/Anderson.

## Acceptance Criteria

- [x] Probe warns when all observed columns are nonnegative magnitudes and
      the estimate may have lost the sign; recommends signed point values
- [x] Probe estimates the eigenvalue correctly from |x| of an alternating
      divergent sequence where possible, or at least flags it
- [x] `empirical_rate` is finite/meaningful on exactly converging traces
- [x] New skill `nonlinear-gauss-seidel.md` with trigger, mechanism,
      evidence (arm B), and the optimal-relaxation rule xi = lambda/(lambda-1)
- [x] Tests red then green; validation still 19/19

## Approach

Test-first fixes in `adsd/probes.py`; new skill file; README/skill
cross-references. Sign loss cannot be undone from magnitudes, so the probe
flags it (`sign-ambiguous` when all observables are >= 0 and the dominant mode
looks real positive with rho >= 0.9) and the README now asks for signed point
values; `short-trace` for < 12 rows (arm B's misleading run used 5 rows).

## Log

- `empirical_rate`: only pairs of resolved increments (> 1e-9 max) are used;
  reproduced the bug with a 4-decimal quantised trace (2.4e23 before).
- Oscillation finding reports optimal relaxation xi = lambda/(lambda-1) for a
  real negative mode (the rule arm B used for the wall vorticity), and
  recommends `nonlinear-gauss-seidel` when |lambda| > 1.5 (also for divergent).
- New `adsd/skills/nonlinear-gauss-seidel.md` (evidence: pilot arm B).
