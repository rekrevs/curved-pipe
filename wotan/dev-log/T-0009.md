## Context

With the turbulent solver running and validated against Ito (1959), this phase
produces comparison plots and writes up the results. The goal is a clear, documented
comparison between the laminar (C&D 1975) and turbulent (Van Driest) solutions,
with honest acknowledgement of the model limitations.

## Acceptance Criteria

- [ ] Run both laminar and turbulent solvers at De = 1000, 2000, 3500, 5000
- [ ] Plot phi_M vs De: laminar and turbulent on same axes
- [ ] Plot w_M vs De: laminar and turbulent on same axes
- [ ] Plot u⁺ vs y⁺ profiles at selected De values, overlaid with log-law
- [ ] Compare mean axial velocity W(r) profiles vs Hüttl & Friedrich (2001) DNS at Re_bulk ≈ 5300 (De ≈ 1190)
- [ ] Limitations clearly documented: isotropic model misses outer-wall vortex (Lai 1991)
- [ ] Update CLAUDE.md with turbulent solver description and validation summary

## Reference Data

**Hüttl & Friedrich (2001)** mean axial velocity profiles at κ = 0.1, Re_bulk = 5300:
- De ≈ 1676 (with δ = κ = 0.1, De = Re × sqrt(2κ) ≈ 5300 × 0.447 ≈ 2370)
- Use their Figure 3 (mean streamwise velocity contours) as qualitative reference
- Exact profile data may need to be digitised from the paper

### Design decisions

- **Separate plot script** rather than extending `plot_dean_flow.py`: The turbulent
  comparison has different data sources (stdout parsing vs .dat files) and different
  plot types. Keeping them separate avoids coupling.

- **DNS comparison noted as qualitative only**: Huttl & Friedrich (2001) data was not
  digitised from their paper. A note in the u+ plot acknowledges this.

- **All four D values on the u+ plot**: Shows how the resolved y+ range grows with D
  (from ~20 at D=1000 to ~48 at D=5000). The profiles clearly follow the viscous
  sublayer near the wall.

### Key physical observations from the plots

1. **phi_M (secondary flow)**: Turbulent phi_M is slightly higher than laminar at
   the same D -- turbulent momentum transport enhances secondary flow.

2. **w_M (peak axial velocity)**: Turbulent w_M is lower than laminar -- the flatter
   turbulent velocity profile (eddy viscosity) reduces the peak relative to the mean.

3. **Friction factor**: Solver results fall within 20% of Ito (1959), with the slope
   matching well across the Re range. All points fall below Blasius (curved pipe
   friction below straight pipe in this regime).

4. **u+ vs y+ profiles**: Near-wall region follows the viscous sublayer (u+ = y+).
   Profiles peak and then decline toward the center -- this is a curvature effect
   (centrifugal force pushes high-momentum fluid outward).
