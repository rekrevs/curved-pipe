# T-0003: Step E: Carry Fox corrections between D cases

**Status**: BLOCKED (after T-0001) | **Size**: S

## What

At high D, the correction smoothing omega1 is small (0.1, 0.05, 0.01). Resetting C0_CORR and E0_CORR to zero at the start of each case forces the algorithm to "relearn" the correction terms from scratch right where the nonlinear coupling is hardest.

Instead, carry corrections from the previous D case as initial guess for the next.

### Implementation

1. Add storage arrays:
```fortran
REAL(dp) :: C0_SAVE(NRP1,NAP1), E0_SAVE(NRP1,NAP1)
```

2. Initialise them once at program start:
```fortran
C0_SAVE(:,:) = 0.0_dp
E0_SAVE(:,:) = 0.0_dp
```

3. Replace the per-case reset:
```fortran
C0_CORR(:,:) = 0.0_dp
E0_CORR(:,:) = 0.0_dp
```
with:
```fortran
C0_CORR(:,:) = C0_SAVE(:,:)
E0_CORR(:,:) = E0_SAVE(:,:)
```

4. At the end of the case (after corrections have converged), save:
```fortran
C0_SAVE(:,:) = C0_CORR(:,:)
E0_SAVE(:,:) = E0_CORR(:,:)
```

This gives D=2000 a much better starting correction (especially important because omega1=0.1 implies slow correction updates).
