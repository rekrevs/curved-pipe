## Approach

### Option F1: 2-cycle averaging (cheap, very effective for exactly this symptom)

Add storage for the previous iterate (one extra copy is enough):

```fortran
REAL(dp) :: PHI_PREV(NRP1,NAP1), W_PREV(NRP1,NAP1), OMG_PREV(NRP1,NAP1)
LOGICAL :: HAVE_PREV
HAVE_PREV = .FALSE.
```

At the end of each outer iteration (after all smoothing), do:

```fortran
IF (.NOT. HAVE_PREV) THEN
  PHI_PREV(:,:) = PHI(:,:,3)
  W_PREV(:,:)   = W(:,:,3)
  OMG_PREV(:,:) = OMEGA(:,:,3)
  HAVE_PREV = .TRUE.
ELSE
  ! detect a 2-cycle using a scalar indicator (maxPHI works fine)
  IF ( (phi_max - phi_max_prev) * (phi_max_prev - phi_max_prev2) < 0._dp ) THEN
     PHI(:,:,3)   = 0.5_dp*(PHI(:,:,3)   + PHI_PREV(:,:))
     W(:,:,3)     = 0.5_dp*(W(:,:,3)     + W_PREV(:,:))
     OMEGA(:,:,3) = 0.5_dp*(OMEGA(:,:,3) + OMG_PREV(:,:))
  END IF

  PHI_PREV(:,:) = PHI(:,:,3)
  W_PREV(:,:)   = W(:,:,3)
  OMG_PREV(:,:) = OMEGA(:,:,3)
END IF
```

You'll need to maintain phi_max_prev2 (just another scalar). This is basically "Anderson depth 1 by hand" tailored to a 2-cycle. It's crude but extremely robust.

### Option F2: Adaptive relaxation on the wall BC only (more elegant, still local)

Instead of a fixed XI(3), compute an iteration-dependent alpha_wall (where alpha_wall = 1 - XI(3)), based on whether the wall residual is oscillating.

A simple rule that works well in practice:
- If RES_WALL increased (or changed sign pattern) vs previous iteration: halve alpha_wall.
- If RES_WALL decreased monotonically for N iterations: increase alpha_wall by ~20% up to a cap.

This gives you "fast when stable, damped when not".
