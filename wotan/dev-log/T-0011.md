# T-0011: ADSD library: executable diagnostic probes + retained solver skills from the C&D work

**Status**: DONE | **Size**: L
**Phase**: -

## Context

ADSD's core artefacts are (a) diagnostic probes — executable checks that turn
"the solver is bad" into "the solver is bad *because* X" — and (b) skills —
reusable remedies packaged with usage instructions and evidence. T-0010
identifies which of each our C&D work produced. This task builds them as a
small, tested library that a fresh agent (T-0012) can use on a different
starting point.

## Acceptance Criteria

- [x] `adsd/probes.py`: solver-agnostic probes operating on an iteration trace
      (per-outer-iteration state vectors or scalar diagnostics), at least:
      oscillation period detection, dominant eigenvalue (incl. complex /
      negative) estimate of the fixed-point map, false-convergence check for
      relaxed updates, non-finite / masked-NaN check
- [x] Unit tests on synthetic linear fixed-point maps with known spectra
      (red before implementation, green after)
- [x] Probes validated on real traces from this repo's history: the pre-T-0004
      solver at D>=2000 must be diagnosed as oscillatory with |lambda| >~ 1 and
      a negative/complex dominant eigenvalue; a converging case (D<=1000) must
      be diagnosed as contractive
- [x] `adsd/skills/`: one file per retained skill (remedy + diagnosis that
      calls for it + Fortran snippet + evidence dossier pointing to dev-logs
      and measured effect)
- [x] A CLI entry point a fresh agent can run on a trace file

## Verification Plan

### Hard Endpoints

- [x] `python -m pytest adsd/tests -q` — probes correct on known spectra
- [x] `python -m adsd.probes <trace>` on real pre-T-0004 traces — diagnosis
      matches what the dev-logs established
- [x] `ruff check --select=F,B,PLE adsd` clean

### Manual Checks

- [x] Each skill file cites the evidence it rests on

### Risks

- Real traces are noisy (SOR inner tolerance, nonlinearity) -> estimate
  eigenvalues by least squares over a window, report confidence
- Main solver must not change numerics -> trace collection only on scratch
  copies of historical commits

## Approach

Python probes operating on per-iteration traces (solver-agnostic), skills as
markdown + standalone Fortran where code is needed. Validate on real traces by
re-building historical/counterfactual solver variants from git with a
trace-only patch, in a scratch dir (`adsd/validation/solver_traces.py`), and
encoding each known-answer hypothesis as a check (`adsd/validation/analyze.py`).

## Implementation Notes

- `adsd/probes.py`: `estimate_spectrum` (vector Prony recurrence on successive
  differences, order 1-4, lowest adequate order; nonlinear fallback = envelope
  ratio + autocorrelation period when the linear fit residual > 0.2),
  `detect_period`, `relaxation_inflation`, `check_false_convergence`,
  `check_nonfinite` (incl. masked-NaN suspect), `check_collapse` (plateau ->
  drop below 50% -> stays down), `diagnose` (maps findings -> skills), CLI.
- `adsd/skills/*.md`: 6 skills with trigger / mechanism / implementation /
  pitfalls / evidence. `adsd/skills/fortran/anderson_mod.f90` (standalone AA,
  same algorithm and safeguards as ANDERSON_OUTER_UPDATE) + test;
  `nan_max_probe.f90`.
- CLAUDE.md corrected (period-2 claim, NaN rule, iteration-order caveat) and
  adsd entries added.

## Obstacles

- First real-trace run: probe called the T-0003 D>=2000 limit cycle
  "contractive" (linear fit residual 0.4-0.6 on a slow nonlinear relaxation
  oscillation). Added the nonlinear branch (test first).
- Collapse check needed two revisions on real data: (1) collapse earlier in
  the trace, (2) oscillation troughs / transients after a drop. These were
  tuned on H1-H3 data, so H1-H3 are not out-of-sample; added held-out grid (c)
  check H5.
- Spectral estimates during D-stepping are meaningless (map changes every 20
  its); added fixed-D counterfactual runs instead.

## Outcome

Library in `adsd/`, validation write-up in `docs/adsd/probe-validation.md`.
Main scientific by-product: the retained explanation for 2-cycle averaging
was wrong on grid (b) (complex pair ~45 deg crossing |lambda|=1 at D~1400,
not lambda=-1); the grid (c) period-3 claim was confirmed exactly on held-out
data. Side observation not investigated: averaging on/off end at slightly
different corrected solutions (D=1300: phi_M 10.67 vs 10.49), most likely
different stopping.
