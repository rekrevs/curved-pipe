# T-0011: ADSD library: executable diagnostic probes + retained solver skills from the C&D work

**Status**: ONGOING | **Size**: L
**Phase**: -

## Context

ADSD's core artefacts are (a) diagnostic probes — executable checks that turn
"the solver is bad" into "the solver is bad *because* X" — and (b) skills —
reusable remedies packaged with usage instructions and evidence. T-0010
identifies which of each our C&D work produced. This task builds them as a
small, tested library that a fresh agent (T-0012) can use on a different
starting point.

## Acceptance Criteria

- [ ] `adsd/probes.py`: solver-agnostic probes operating on an iteration trace
      (per-outer-iteration state vectors or scalar diagnostics), at least:
      oscillation period detection, dominant eigenvalue (incl. complex /
      negative) estimate of the fixed-point map, false-convergence check for
      relaxed updates, non-finite / masked-NaN check
- [ ] Unit tests on synthetic linear fixed-point maps with known spectra
      (red before implementation, green after)
- [ ] Probes validated on real traces from this repo's history: the pre-T-0004
      solver at D>=2000 must be diagnosed as oscillatory with |lambda| >~ 1 and
      a negative/complex dominant eigenvalue; a converging case (D<=1000) must
      be diagnosed as contractive
- [ ] `adsd/skills/`: one file per retained skill (remedy + diagnosis that
      calls for it + Fortran snippet + evidence dossier pointing to dev-logs
      and measured effect)
- [ ] A CLI entry point a fresh agent can run on a trace file

## Verification Plan

### Hard Endpoints

- [ ] `python -m pytest adsd/tests -q` — probes correct on known spectra
- [ ] `python -m adsd.probes <trace>` on real pre-T-0004 traces — diagnosis
      matches what the dev-logs established
- [ ] `ruff check --select=F,B,PLE adsd` clean

### Manual Checks

- [ ] Each skill file cites the evidence it rests on

### Risks

- Real traces are noisy (SOR inner tolerance, nonlinearity) -> estimate
  eigenvalues by least squares over a window, report confidence
- Main solver must not change numerics -> trace collection only on scratch
  copies of historical commits
