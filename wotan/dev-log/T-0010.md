# T-0010: ADSD retrospective: map T-0001..T-0005 to diagnose->discover->implement->retain

**Status**: DONE | **Size**: M
**Phase**: -

## Context

Chen & Yin, *Training Numerical Intelligence via Auto-Diagnosis and Skill
Discovery* (arXiv:2610.03872, Oct 2026) propose ADSD: an agent first diagnoses
*why* a solver performs poorly (executable probes, hypotheses validated on a
held-out pool), uses the diagnosis to guide literature/method discovery,
implements, and retains successful improvements as reusable skills
(code + usage instructions + evidence dossier).

The C&D (1975) reconstruction in this repo (Step 0, T-0001..T-0005) was in
effect a manual, human-orchestrated ADSD run (Claude Code as hands, ChatGPT as
diagnostician, human as router). This task makes that mapping explicit, as the
basis for the probe/skill library (T-0011) and the pilot (T-0012).
