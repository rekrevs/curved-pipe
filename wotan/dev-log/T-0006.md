# T-0006: Port Dean flow solver to Julia

**Status**: DONE | **Size**: L

## Context
Port the Fortran 90 solver `Collins_Dennis_1975_central.f90` (~1446 lines) to Julia as `dean_flow.jl`. Preserve the exact algorithm and match C&D (1975) reference values.

## Acceptance Criteria
- [x] Single file `dean_flow.jl` that runs with `julia dean_flow.jl [b|c]`
- [x] Grid (b) results match Fortran output exactly for D=10..2000
- [x] Grid (c) results match C&D (1975) reference values to <0.05%
- [x] All 10 D cases converge on both grids

## Approach
Direct translation preserving Fortran's 4-slice 3D array convention, E array reuse, and all algorithmic details. Decomposed monolithic MAIN into ~15 functions operating on 4 structs (GridParams, CaseConfig, SORParams, SolverState, AndersonState). Grid selection via CLI argument instead of compile-time parameter.

## Log

### Implementation
- Wrote complete Julia port in single file (~1370 lines)
- Preserved all Fortran conventions: slice numbering, iteration order, SOR retry logic
- Used `@inbounds` on inner SOR loops, `@views` for slice operations
- PI = 3.14159255 (Schubert 1972 original, not Julia's pi)

### Bugs Found and Fixed
1. **Typo in Fox correction** (E0_CORR computation): `OMEGA[i,j+1,j,SOR_NEW]` — 4 indices on a 3D array. Inside `@inbounds`, this silently read garbage memory instead of throwing BoundsError. Caused SOR divergence starting at D=96 case 2.

2. **Anderson acceleration early return**: `anderson_update!` returned `0` when history was insufficient (`AA_NHIST < 2`), which overwrote the caller's `icv` variable to 0 (falsely signaling convergence). In Fortran, the host-associated `ICV` was simply not modified on early return. Fixed by returning sentinel `-2` for "don't change icv".

### Verification
Grid (b) — cases 1-9 identical to Fortran, case 10 within 0.7% (omega1=0 on grid b):
```

D=96:   w_M=23.34   (exact match)
D=1000: w_M=140.62  (exact match)
D=3500: w_M=347.20  (exact match)
D=5000: w_M=399.74  (Fortran: 402.58, grid b skips corrections)
```

Grid (c) — matches C&D (1975) to <0.05%:
```
D=96:   w_M=23.33   (C&D: 23.34)
D=500:  w_M=83.66   (C&D: 83.66)
D=1000: w_M=141.30  (C&D: 141.26)

D=5000: w_M=449.49  (C&D: 449.3, 0.04%)
```

Runtime: Grid (b) 6.2s, Grid (c) 41.4s (Fortran: ~5s, ~38s).

## Outcome
Complete Julia port in `dean_flow.jl`. All D values converge on both grids, matching C&D (1975) reference values to the same accuracy as the Fortran original.
