# T-0001: Steps A+B+C: Fix convergence checking, add wall BC diagnostic, stabilise D>=2000 XI params

**Status**: READY | **Size**: M
**Phase**: —

## Context

The outer iteration at D >= 2000 is trapped in a limit cycle. The root cause is twofold:
1. The convergence test measures the *relaxed* update `(1-XI) * (raw - old)`, so large XI values cause false convergence to under-developed (near-trivial) solutions.
2. The XI parameters for D >= 2000 are not aggressive enough to damp the coupled feedback loop PHI <-> Omega_wall (amplification factor 2/h^2 = 800).

This task fixes the convergence logic (Step A), adds a wall BC residual diagnostic (Step B), and applies stabilised XI parameters for high D (Step C).

## Approach

### Step A — Fix convergence checking to be consistent with relaxation

#### A1) Patch SMOOTH so EPS refers to the raw update (unrelaxed)

In `MODULE SOR_MOD`, `SUBROUTINE SMOOTH`, change the convergence check:

**Current**
```fortran
ARR(I,J,3) = XI*ARR(I,J,1) + XIC*ARR(I,J,3)
IF (ABS(ARR(I,J,1)-ARR(I,J,3)) > EPS) ICV = 1
```

**Replace with**
```fortran
ARR(I,J,3) = XI*ARR(I,J,1) + XIC*ARR(I,J,3)
! Convergence must be judged on the *unrelaxed* update:
! (old - relaxed) = XIC*(old - raw_new)
IF (ABS(ARR(I,J,1)-ARR(I,J,3)) > XIC*EPS) ICV = 1
```

This single change prevents "false convergence" when XI is large.

#### A2) Apply the same fix to the two non-SMOOTH convergence checks

##### W at origin smoothing check

Find:
```fortran
IF (ABS(W(1,1,1) - W(1,1,3)) .GT. EPS(2)) ICV = 1
```

Change to:
```fortran
IF (ABS(W(1,1,1) - W(1,1,3)) .GT. XIC(2)*EPS(2)) ICV = 1
```

##### Omega wall BC update check

Find:
```fortran
IF (ABS(OMEGA(NRP1,J,1) - OMEGA(NRP1,J,3)) .GT. EPS(3)) ICV = 1
```

Change to:
```fortran
IF (ABS(OMEGA(NRP1,J,1) - OMEGA(NRP1,J,3)) .GT. XIC(3)*EPS(3)) ICV = 1
```

After these edits, "EPS" means what you actually want it to mean: a tolerance on the underlying fixed-point update, not on the damped increment.

### Step B — Add a residual-based wall BC diagnostic (and optionally gate convergence on it)

Right after setting the wall BC (right after the `DO J=2,NA` loop that sets `OMEGA(NRP1,J,3)`), compute:

```fortran
REAL(dp) :: RES_WALL
RES_WALL = 0.0_dp
DO J = 2, NA
  RES_WALL = MAX(RES_WALL, ABS(OMEGA(NRP1,J,3) + 2._dp*RINV2(2)*PHI(NR,J,3)))
END DO
```

Print it in the DIAG block (with the other max-values) so you can see whether you're actually satisfying the wall closure.

Optionally (recommended for D>=2000 while debugging): force outer iteration to continue unless the BC residual is small:
```fortran
IF (RES_WALL .GT. EPS(3)) ICV = 1
```

Why this helps: it makes it impossible for a heavily under-relaxed run to claim convergence while still violating the wall condition.

### Step C — Stabilise D>=2000 with deliberate damping on all coupled fields

With the propagation fix, the true coupled mapping has stronger feedback than Schubert's "accidentally damped" version. At high D, damping only the wall is usually not enough; you must reduce the effective gain of the full loop: Omega -> phi -> (Omega_wall, advection) -> Omega.

Replace XI for cases 8-10:
```fortran
XI_CASES(:,8)  = (/0.85_dp, 0.50_dp, 0.90_dp, 0.85_dp/)   ! D=2000
XI_CASES(:,9)  = (/0.90_dp, 0.60_dp, 0.93_dp, 0.90_dp/)   ! D=3500
XI_CASES(:,10) = (/0.93_dp, 0.65_dp, 0.95_dp, 0.93_dp/)   ! D=5000
```

Rationale:
- `XI(1)` (PHI smoothing): damp the immediate response of phi to changes in Omega.
- `XI(4)` (Omega interior smoothing): damp the propagation of wall-driven Omega changes into the interior.
- `XI(2)` (W smoothing): moderate relaxation on W prevents source term jumps that drive oscillations even if the wall is damped.
- `XI(3)` (wall): keep it high.

Because Step A fixed the convergence test, using XI(3)=0.9-0.95 will NOT "converge to trivial"; it will simply take whatever iterations are needed until the raw updates are small.
