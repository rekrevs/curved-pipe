# T-0012: ADSD pilot: fresh agent from Schubert solver, with vs without library, scored against C&D

**Status**: DONE | **Size**: L
**Phase**: -

## Context

Does a retained diagnosis/skill library actually help a fresh agent? Pilot
experiment, two arms, same task, same model, same budget:

- Arm A (baseline): fresh agent, Schubert (1972) upwind solver + C&D target
  table + Fox correction formulae; no library.
- Arm B (ADSD): identical, plus `adsd/` probes and skills.

"Fresh" = headless `claude -p` run from an isolated workspace outside the repo,
so the project CLAUDE.md, memory and dev-logs are not in context.

This is an N=1-per-arm pilot: it can show feasibility and gross effects, not
statistically meaningful differences. The library is derived from this very
problem, so arm B measures actionability of retained skills (in-distribution
reuse), not transfer to new problems.

## Approach

Headless `claude -p` per arm, started in a scratch workspace outside the repo
(no project CLAUDE.md/memory), `--restricted` + `--strict-mcp-config`, no web,
outer OS sandbox. Frozen task spec committed before launch (`e1394e8`).
Scoring by our own compile+run of each final `solver.f90`; 1% tolerance for
D<=2000 (pure upwind misses by 1.6-8.6%, measured with corrections disabled in
our solver), 3% phi_M + converged for D=3500/5000.

## Implementation Notes

- `adsd/pilot/pilot.py` (setup/run/score/audit), `TASK.md`, addendum.
- Upwind reference values measured by setting all OMEGA1_CASES to 0 in a
  scratch copy of the grid (b) solver.
- Env ANTHROPIC_API_KEY has no credit -> runs use the claude.ai login
  (`env -u ANTHROPIC_API_KEY`); network allowed only to api.anthropic.com.
- Nested agent's own sandbox fails to start inside ours; it still runs inside
  our outer sandbox (verified by smoke tests; restricted mode refused a Read
  of the repo README).

## Obstacles

- None blocking. Arm A reports a possibly orphaned bounded process (`./s
  upwind` in its scratch work dir; its sandbox disallowed ps/kill).

## Verification Evidence

- Score (independent): arm A 7/7, arm B 7/7; identical values to the printed
  digit (e.g. D=2000 13.3691 / 234.524; D=5000 20.4271 / 443.990).
- Audit: no tool input referencing the repo, ~/.claude/projects, other
  absolute user paths, or (arm A) adsd. Arm B ran probes 15x.
- Metrics: A 55.1 min / USD 2.72 / 18 compiles; B 54.2 min / USD 3.85 / 20
  compiles; final solver runtime A 93 s, B 8.5 s.
- Transcripts checked for secrets (apiKeySource none) before archiving.

## Outcome

`docs/adsd/pilot.md` + `docs/adsd/pilot-artifacts/`. Ceiling effect: library
did not change success or time on this task; it changed the route (measured
eigenvalues -> structural fix, nonlinear Gauss-Seidel, 11x faster solver) and
fed back two probe defects + one new skill candidate (-> T-0014). Both agents
converged full corrections at D=5000 on grid (b), which our solver skips
(-> IDEA T-0016). Sharper test needed (-> IDEA T-0015).
