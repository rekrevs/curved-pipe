# T-0012: ADSD pilot: fresh agent from Schubert solver, with vs without library, scored against C&D

**Status**: BLOCKED (after T-0011) | **Size**: L
**Phase**: -

## Context

Does a retained diagnosis/skill library actually help a fresh agent? Pilot
experiment, two arms, same task, same model, same budget:

- Arm A (baseline): fresh agent, Schubert (1972) upwind solver + C&D target
  table + Fox correction formulae; no library.
- Arm B (ADSD): identical, plus `adsd/` probes and skills.

"Fresh" = headless `claude -p` run from an isolated workspace outside the repo,
so the project CLAUDE.md, memory and dev-logs are not in context.

This is an N=1-per-arm pilot: it can show feasibility and gross effects, not
statistically meaningful differences. The library is derived from this very
problem, so arm B measures actionability of retained skills (in-distribution
reuse), not transfer to new problems.

## Acceptance Criteria

- [ ] Isolated workspaces with frozen task spec; identical except the library
- [ ] Both arms run to completion or budget; transcripts captured
- [ ] Transcripts audited for contamination (reads of the repo / solution)
- [ ] Results scored by an independent script against the C&D grid (b) table
- [ ] Results + threats to validity recorded in `docs/adsd/pilot.md`
